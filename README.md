# 🐍 Snaky.io

Неоновая .io-змейка в браузере: большая арена, боты-соперники, рост, ускорение
и онлайн-таблица рекордов. Хостинг и сервер — **Vercel**.

## Механика

- Змейка плавно поворачивает к курсору (или по джойстику) и ест светящиеся точки — так растут счёт и длина.
- **Ускорение** тратит длину: за змейкой остаётся след из еды.
- Врезался головой в чужое тело или в границу арены — проиграл. Тело погибшей змейки рассыпается едой.
- Подрежьте бота своим телом — он погибнет, а вам засчитается победа.
- 16 ботов с ИИ: ищут еду, уворачиваются от препятствий и охотятся на игрока.
- У лидера над головой корона. В верхнем правом углу — живой топ игроков.
- 2 секунды неуязвимости после появления (змейка мигает).

## Управление

| | Компьютер | Телефон |
|---|---|---|
| Направление | мышь, ← → или A / D | джойстик слева |
| Ускорение | ЛКМ, пробел, ↑ / W | кнопка ⚡ справа |
| Пауза | Esc / P | кнопка ⏸ |

## Структура

```
public/              статика (раздаётся Vercel как сайт)
  index.html         экраны: меню, HUD, пауза, итоги, настройки
  style.css          дизайн-система (тёмная неоновая тема)
  js/main.js         состояния игры, интерфейс, главный цикл
  js/game.js         мир: змейки, еда, столкновения, ИИ ботов
  js/render.js       отрисовка на canvas
  js/input.js        мышь, клавиатура, джойстик
api/
  scores.js          серверная функция Vercel: GET/POST /api/scores
vercel.json          конфигурация Vercel
```

## Деплой на Vercel

1. Зайдите на https://vercel.com/new и импортируйте этот GitHub-репозиторий.
2. Framework Preset: **Other**, остальные настройки оставьте по умолчанию → **Deploy**.
3. (Рекомендуется) Подключите хранилище для рекордов:
   **Project → Storage → Create Database → Upstash (Redis)** → привяжите к проекту.
   Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
   Затем сделайте **Redeploy**.

Без хранилища игра тоже работает, но рекорды хранятся в памяти функции и сбрасываются.

После этого каждый `git push` в репозиторий автоматически деплоится.

## Локальный запуск

```bash
npm i -g vercel
vercel dev
```

Откройте http://localhost:3000.
